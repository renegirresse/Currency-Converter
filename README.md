This is a fully-functional currency converter with real-time exchange rates, offline capabilities, and a sleek UI. 
This showcases my skills in Python development, API integration, and problem-solving.

## 🚀 **Project Highlights** 

### 🔥 **KEY FEATURES**
- **Real-time currency conversion** using live exchange rates
- **179 supported currencies** with automatic rate updates
- **Offline mode** with cached exchange rates
- **Sleek dark theme UI** with intuitive controls
- **Multi-API fallback system** for maximum reliability


### 🔧 **Technical Stack**

- Python 3 (Core logic)

- Tkinter (GUI development)

- Forex-Python & ExchangeRate-API (Real-time currency data)

- Requests library (API calls)

- Threading (Background processing)

- JSON (Data handling)



### 💪 **Challenges I Overcame**

- Handling API rate limits and failures gracefully

- Implementing currency conversion through intermediate currencies

- Creating a responsive UI that works across different systems

- Ensuring accurate calculations with proper rounding
